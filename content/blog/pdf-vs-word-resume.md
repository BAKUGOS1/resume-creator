## Quick answer

Follow the employer’s requested file type first. If no format is specified, a text-based PDF preserves your layout; DOCX is useful when Word is requested or editable content is needed. Avoid image-only PDFs, and check that the exported text can be selected and read in order.

Short answer: **send a text-based PDF unless the employer asks for Word.** Here’s the reasoning, and the cases where .docx is the better choice.

## Why PDF is usually the right default

- **It looks the same everywhere.** Fonts, spacing and page breaks don’t shift between Word versions, Google Docs, Macs and phones.
- **Modern ATS platforms read text-based PDFs well.** The text is stored as real characters, so it can be extracted and searched.
- **It’s harder to edit by accident** when it’s forwarded around.

The key phrase is _text-based_. A PDF made by scanning or exporting an image (common with some design tools) contains no text at all — an ATS sees a blank page. Test yours: open the PDF and try to select and copy a sentence. If you can paste it into a text editor in the right order, it’s fine.

## When to send Word (.docx)

- The job posting or portal **explicitly asks for .docx**.
- A **recruitment agency** wants to edit it — many reformat CVs onto their own letterhead.
- An **older or unusual ATS** rejects PDF uploads.

Some ATS guides rank .docx as the most universally accepted format, so if you’re unsure and the portal accepts both, either is fine; consistency with the instructions matters more.

## When to send plain text

Some application forms ask you to paste your resume into a box. Use a plain-text version so formatting characters don’t turn into symbols. Keep the same section order and use simple dashes for bullets.

## A quick decision table

| Situation                                 | Send                        |
| ----------------------------------------- | --------------------------- |
| Online application, both formats accepted | PDF                         |
| Posting says “Word” or “.docx”            | Word                        |
| Emailing a hiring manager or recruiter    | PDF                         |
| Recruitment agency                        | Word (they may reformat it) |
| “Paste your resume” text box              | Plain text                  |
| Sharing on your website or LinkedIn       | Web page or PDF             |

## How to check your PDF is ATS-readable

Run this two-minute test before you apply anywhere:

1. **Select all text** in the PDF (Ctrl/Cmd + A). If nothing highlights, the file is an image — re-export it.
2. **Copy and paste into a plain text editor.** Your name, headings, job titles and dates should appear in reading order, not interleaved.
3. **Check special characters.** Bullets, dashes and accented letters (é, ü, ñ) should paste as the same characters, not boxes or question marks.
4. **Click your links.** Email, LinkedIn and portfolio links should open.
5. **Check the file size.** A one- or two-page text resume is usually well under 1 MB. A multi-megabyte file often means embedded images.

If the pasted text comes out scrambled, the layout is the problem — usually columns, tables or text boxes. See [ATS resume format](/blog/ats-resume-format/) for what to change.

## What about Google Docs, Canva and other tools?

- **Google Docs:** _File → Download → PDF_ produces a text-based PDF, and _Microsoft Word (.docx)_ works when Word is requested.
- **Design tools:** check the export settings. Some export pages as images or split text into many small boxes that parse out of order. Run the copy-paste test above.
- **Apple Pages:** export to PDF or Word; never upload a `.pages` file.

## Name your file properly

Use `Firstname_Lastname_Resume.pdf`, not `resume_final_v3.pdf`. Recruiters download dozens of files a day.
